How to run

Show setup & usage
  1. Audio routing (once): install BlackHole 2ch. In Audio MIDI Setup create a Multi-Output Device (tick BlackHole + your speakers/interface) and set it as Ableton's output — so you still hear sound while the app reads BlackHole.
  2. Start: open this page in Chrome. Click Refresh, pick BlackHole, then Start. Play a clip in Ableton — the meters should move.
  3. Project: click Open output window →, drag it onto your projector (extended display, not mirrored), and press f for fullscreen. Keep this control window visible on the laptop.
  4. Perform: pick sources A/B + crossfade, tweak colour/effects, choose a Reactivity mode. Set BPM (or Tap) and enable BPM loops for tempo-synced counterpoint motion.
  5. Presets: Save current names a look (recall with its button, keys 1–8 for the first eight, or a learned MPD26 pad).
  6. MIDI (optional): Connect MIDI, then Learn next to a parameter or preset and move/press a control. Reset mappings clears all.
  7. Quality: the Quality slider under Output scales the internal render resolution (100% = full). On a big/4K projector or if frames drop, lower it (e.g. 60–75%) for GPU headroom — visuals get slightly softer but run smoother. It's a per-machine setting, not saved in presets. Also keep the laptop plugged in to avoid GPU power-throttling.
