How to run

Show setup & usage
  1. Audio routing (once): install BlackHole 2ch. In Audio MIDI Setup create a Multi-Output Device (tick BlackHole + your speakers/interface) and set it as your DAW's output — so you still hear sound while the app reads BlackHole.
  2. Start: open this page in Chrome. Click Refresh, pick BlackHole, then Start. Play something in your DAW — the meters should move.
  3. No cable to install? Click System audio instead: Chrome shares your computer's sound through its screen-share dialog (the app discards the video). On Windows pick Entire Screen + tick "Also share system audio". On Mac Chrome only offers a browser tab's audio, so a DAW there still needs BlackHole.
  4. No audio at all? Click No sound instead of Start: the engine runs with no input, so generative sources, BPM loops and Motion keep animating. Good for designing looks away from the DAW or testing the projector. Start hands back to real audio.
  5. Permissions: Chrome asks for the microphone (the only way a browser can receive audio — it reads whichever input you pick), screen share (only for System audio; the video is discarded), and the camera (only for Camera/Motion). Nothing is transmitted anywhere — the app makes no network connections. Revoke any of it via the icon at the left of the address bar.
  6. Project: click Open output window →, drag it onto your projector (extended display, not mirrored), and press f for fullscreen. Keep this control window visible on the laptop.
  7. Perform: pick sources A/B + crossfade, tweak colour/effects, choose a Reactivity mode. Set BPM (or Tap) and enable BPM loops for tempo-synced counterpoint motion.
  8. Presets: Save current names a look (recall with its button, keys 1–8 for the first eight, or a learned MIDI pad/key). Reset (top right) puts every look/effect control back to default — tempo, Quality, MIDI and presets are untouched.
  9. MIDI (optional): Connect MIDI, then Learn next to a parameter or preset and move/press a control — works with any controller (pads/keys trigger presets, knobs/faders drive parameters). Reset mappings clears all.
  10. Quality: the output window always fills your display at full resolution — Quality doesn't change that. It changes how many pixels get shaded internally before that scale-up: 100% = every pixel, 50% = a quarter as many, then scaled up. On a big/4K projector or if frames drop, lower it (e.g. 60–75%) for GPU headroom — visuals get slightly softer but run smoother. It's a per-machine setting, not saved in presets. Also keep the laptop plugged in to avoid GPU power-throttling.
